# 焚き火育成ゲーム

夜空の下の焚き火をゆっくり育てていく Android 向けの放置ゲームです。

- 火を絶やさず燃やすほどレベルが上がり、薪や仲間が手に入る
- 金属を投入すると炎が花火のような色に変わる「炎色反応」
- リス・フクロウ・キツネ・ビーバー・クマ など、火を見守ってくれる動物を雇える
- 流れ星や星座が時々夜空を流れる
